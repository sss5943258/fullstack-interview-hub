# Fullstack Interview Hub (全端工程師面試題庫專案)

🚀 **Fullstack Interview Hub** 是一個專為全端工程師設計的極致備驗面試練習平台。精選近 5 年熱門面試考題，涵蓋 5 大核心領域，幫助工程師在面試中脫穎而出。

---

## 🌟 核心特色 (Key Features)

- **5 大技術領域 (~85+ 高頻精選題目)**
  - ⚛️ **React** (Fiber, Hooks, Concurrent Mode, Virtual DOM, Custom Hooks, Redux Toolkit, Performance)
  - 🅰️ **Angular** (RxJS, Dependency Injection, Change Detection, Modules/Standalone, Zone.js, Signals)
  - ⚡ **.NET Core** (Middleware, Dependency Injection, async/await, Entity Framework Core, Memory Leaks, Kestrel)
  - 🗄️ **SQL & Database** (Indexing, Transaction Isolation Levels, ACID, Execution Plan, N+1 Problem, Sharding)
  - 🐳 **K8s & Docker** (Container Lifecycle, K8s Pod/Deployment/Service, Ingress, Persistent Volume, Helm)

- **4 大刷題練習模式**
  1. 📚 **題庫瀏覽 (Question Bank)**：按領域與難度 (Junior/Mid/Senior) 快速篩選，搜尋關鍵字，查看程式範例與面試重點。
  2. 🎴 **3D 翻牌刷題 (Flashcard Mode)**：質感 3D 翻牌動畫，訓練自我回想能力與評估精通度。
  3. 📝 **模擬測驗 (Mock Quiz Mode)**：隨機抽選考題單選測驗，即時計算得分與完整檢討分析。
  4. 📊 **學習進度追蹤 (Progress Tracker)**：統計圖表，自動保存精通題目、收藏清單與測驗歷史（基於 LocalStorage）。

---

## 🛠️ 技術棧 (Tech Stack)

- **Frontend Core**: React 19 + Vite 6
- **Styling**: Tailwind CSS + Glassmorphism UI + Custom Animations
- **UI Components & Icons**: Ant Design + Lucide Icons
- **State & Storage**: LocalStorage Persistence API

---

## 🚀 快速開始 (Quick Start)

### 1. 安裝依賴
```bash
npm install
```

### 2. 啟動開發伺服器
```bash
npm run dev
```

### 3. 生產環境編譯
```bash
npm run build
```
